Memory note
-----------
The image ends at $9547, leaving $00B8 (184) bytes before the usual
DOS 3.3 $9600 boundary. The module therefore fits, but the remaining
space is intentionally treated as exhausted for later modules.

Scope and limitation
--------------------
The complete real-leaf path is present, but a full real WOTS+ leaf was not
executed end-to-end in this build validation because it is exceptionally
expensive in the instruction-level emulator. Its newly introduced step,
per-leaf S_ots derivation, was machine-tested. WOTS_GEN_PK and XMSS_LTREE
were independently machine-tested in the preceding validated modules.

The BRUN self-test deliberately uses a height-3 synthetic tree. Synthetic
leaves test TreeHash and authentication-path logic only; they are not
cryptographic XMSS leaves.
