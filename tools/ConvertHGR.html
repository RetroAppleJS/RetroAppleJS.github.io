Implementation status

This file implements the ConvertHGR-compatible seven-pixel / 256-pattern quantizer, palette phases, candidate-horizontal D/E diffusion, A/B/C/F error propagation, ordered modes, colour metrics, five resize filters, HGR packing, and Apple II 8 KB memory interleave.

Parity is deliberately not claimed until reference fixtures generated by a fixed-seed desktop ConvertHGR build match byte-for-byte. Histogram Stretch is explicitly a compatibility approximation because the original delegates that operation to the external ImgSource library.

Behavioral reimplementation based on ConvertHGR by Mike Brent (Tursi / HarmlessLion). The original project should be credited and its redistribution terms reviewed before distributing a derived port.
