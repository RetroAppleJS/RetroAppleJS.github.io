How to interpret the test

One batch is outstanding at a time. WebGL2 uses asynchronous completion fences; WebGL1 is explicitly labelled when it uses blocking gl.finish. The sustainable threshold requires at least 95% of requested throughput and p95 batch latency within the batch interval in every repetition. The boundary is refined with two additional requested rates when a passing/failing bracket exists.

The default reuses deterministic precomputed inputs. The optional RAM snapshot setting includes the production-style 24 KiB slice allocation/copy. WASM changes only the dispatch loop; GPU.js still executes in JavaScript. GPU timers and upload-call timings are diagnostic measurements, not physical DMA time.
