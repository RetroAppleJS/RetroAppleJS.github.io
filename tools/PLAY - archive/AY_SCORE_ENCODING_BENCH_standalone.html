6502 execution and memory assumptions



Modeled, not hardware-measured: All decoder code sizes, cycle costs, memory footprints and CPU availability profiles are estimates. IRQ playback runs at nominal CPU speed, preempting graphics and reporting frame-budget conflicts. Cooperative playback runs at nominal speed only in a contiguous tail window of each hypothetical 20 ms graphics frame. Neither model simulates actual instruction interleaving, interrupts, or VIA hardware. Binary sizes and round-trip event comparisons are actual measurements.

Technical scope


E0: fixed six-byte absolute register events. E1: delta-time varints. E2: independently decoded blocks with a bounded 128-event LZ backreference window. E3: compact note/instrument actions expanded to AY writes using shared deterministic synthesis rules. E4: instrument actions plus direct-write escapes, with lossless E2 fallback when smaller.


Exact equivalence means the decoded cycle-ordered chip/register/value writes match the canonical timeline. It does not certify identical audible output or real-hardware VIA bus timing. Imported nanosecond event times are rounded to the configured 6502 cycle clock. E3 intentionally rejects arbitrary register-write input rather than inventing missing musical semantics.


Resident and streamed memory numbers are architectural planning estimates. The prototype does not yet implement a real 6502 assembler player, disk streaming, external-memory support, or PSID ingestion; these belong to subsequent implementation phases.
