Measurement interpretation

Bench v3 tests the current production SID implementation, independent of development phase. Envelope traces are never part of rendering benchmarks. A run starts a new SIDAudio instance for each fixture/model. It includes one untimed warm-up and a median of repeated 44,100-sample renders. The PCM hash confirms repeatability within this environment. Offline render performance is not a substitute for browser Web Audio underrun telemetry; use the existing peripheral audio telemetry for the live 10 FPS/VBLANK comparison. Performance comparisons are meaningful on the same computer and browser, with similar background load. This is a software baseline, not physical 6581/8580 certification.
