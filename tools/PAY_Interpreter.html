Both buttons request your API key in a masked prompt. Test GPT API makes one short, live Responses API request using the selected model; a successful response ID proves the server answered. The key is held in memory for the request only, never saved or shown in the diagnostic log.

Important: API usage can incur charges. Full source batches and the guide are sent to OpenAI. Only use the direct-browser key flow on a device and page you trust. For distributed production use, replace it with a secure backend/proxy. No key is stored in cookies or browser storage.
