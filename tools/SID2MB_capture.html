SIDchipJS → Mockingboard 50Hz stream exporter

Runs the C64's init/play routine in RetroAppleJS's existing jsSID.js emulator, then writes delta-compressed SID register changes for SID2MB_resident.asm.

Select an original .SID/PSID file.

The stream starts at $6000 (max. $5FFF bytes) and uses a fixed 50Hz tick. This is an approximation: its snapshots cannot preserve SID updates occurring between ticks or SID's analog waveforms/filters.
