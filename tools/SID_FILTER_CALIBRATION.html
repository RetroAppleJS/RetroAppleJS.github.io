Sources and calibration boundaries

Published reSID documentation provides a circuit-model basis, including an approximate 8580 0–12.5 kHz cutoff mapping and its modeled resistor-ladder resonance law. These are published emulator/circuit-model references, not recordings of the user's actual chips. The 6581 filter varies among specimens and its op-amp behavior is nonlinear.

reSID filter implementation · reSIDfp filter model documentation · Phase 4D.2 methodology and reference limits

The current tests use an actual triangle oscillator, not an ideal laboratory sine generator, and extract the fundamental with a Hann-window complex projection. This substantially reduces harmonic interference compared with Phase 4D.0's broadband RMS sweeps but does not equal a calibrated physical-chip frequency-response test. Above roughly 5 kHz, the 22,050 Hz sampling budget imposes additional limitations.

Compatibility

Earlier SID Filter Lab (4D.1) and SID Audio Bench v3 remain unchanged. No changes have been made to production filter coefficients, oscillator/ADSR behavior, audio FIFO or native PSID playback in 4D.2a.
