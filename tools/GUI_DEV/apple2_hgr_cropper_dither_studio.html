How this version works Every byte position tests all 256 possible values: seven bitmap bits plus the shared phase bit. Candidates are scored in OKLab over the complete seven-pixel block and its immediate left/right boundary. Alternating refinement passes can replace earlier choices. Only the final row residual is diffused vertically. The preview uses an idealized six-colour HGR artifact model. It is suitable for pattern optimization, but a composite NTSC renderer may produce somewhat different RGB values.
